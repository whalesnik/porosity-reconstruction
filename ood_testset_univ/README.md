# Набор для OOD-детектора: университетский керн, 2D-модель

100 срезов: сухой снимок (вход модели), предсказанный ксенон (выход модели) и
фактическая ошибка модели на этом срезе.

```
input_dry/img_000.png … img_099.png    вход модели, 768×768, 16 бит
pred_xenon/img_000.png … img_099.png   выход модели, тот же срез
labels.csv                             метрики
```

Формат тот же, что у `ood_testset` — существующий код заработает без изменений.

## Чем отличается от прошлого набора

**Один образец вместо двух.** Все 100 срезов — университетский керн 22322-24,
равномерно по всему объёму (z 5…469 из 475). Модель обучена на сколтеховском
керне и **ни одного вокселя этого объёма не видела**, поэтому «свой/чужой» тут
нечего различать: чужие все.

**Файлы не перемешаны.** В прошлом наборе перемешивание защищало от подсказки
по именам, какой срез из какого образца. Здесь скрывать нечего, поэтому файлы
идут по порядку z, а сам z есть в `labels.csv`.

**Модель — 2D U-Net** (`2d_unet_l1`, эпоха 22). 2.5D по этому набору прогнать
нельзя: ей нужны пять соседних срезов, и набор пришлось бы собирать иначе.

## Числа

| метрика | медиана | размах |
|---|---|---|
| `phi_abs_error` | 1.32 п.п. | 0.01 … 3.33 |
| `mae` | 14.04 п.п. | 12.18 … 15.84 |

Для сравнения, сколтеховская половина прошлого набора: `phi_abs_error` 1.00,
`mae` 5.93. То есть на этом образце **локальная точность падает вдвое, а
интегральная почти нет** — это и есть главный результат, который набор должен
помочь объяснить.

Оговорка про `mae`: она почти целиком определяется шумом эталона (σ_φ = 12.9 п.п.
здесь против 3.5 на сколтеховском скане). Детектор, предсказывающий `mae`,
обнаруживает «другой прибор», а не «модель ошиблась». Трудная и содержательная
цель — `phi_abs_error`.

## Обе версии по смещению — как вы просили

| вариант | колонка | медиана | среднее |
|---|---|---|---|
| как есть | `phi_abs_error` | 1.32 | 1.38 |
| поправка перенесена со Сколтеха | `phi_abs_error_debiased` | **0.76** | 0.91 |
| оракул, константа подогнана по этому образцу | `phi_abs_error_debiased_oracle` | 0.71 | 0.89 |

Константа для средней строки — **−1.022 п.п.**, измерена на 15 чистых
сколтеховских срезах из калибровочного набора. Именно её и можно применить
в эксплуатации: подобрать константу по этому образцу нельзя, для этого нужен
его ксеноновый скан, а мы ровно от него и избавляемся.

Хорошая новость: перенесённая константа (−1.022) почти совпадает с собственной
константой образца (−1.205), поэтому и результат почти как у оракула — 0.76
против 0.71. То есть смещение **переносится между образцами**, а не является
свойством конкретного керна. Это уже пригодно к применению.

Для детектора тут есть отдельный вопрос: если поправка убирает половину ошибки,
то и калибровочная кривая «скор → ошибка» должна строиться по исправленной
версии. Иначе кривая будет описывать в основном константу, а не то, что детектор
способен предсказать.

## PNG без нормировки

16 бит, сырые единицы КТ. Приводить к какой-либо шкале здесь нельзя: разница
шкал между образцами и есть тот сигнал, который канал условий съёмки должен
ловить. Если нормировка нужна, константы в `labels.csv`:

```python
x = (img.astype("float32") - offset) / scale
```

Учтите, что `offset` и `scale` у этого образца **свои** (17266.6 и 21205.4
против 7381.5 и 4797.1 у сколтеховского). Они подобраны так, чтобы сохранялось
отношение `scale / ΔI₁₀₀` — именно оно переводит выход сети в пористость.

## Колонки labels.csv

| колонка | что это |
|---|---|
| `id` | имя файла в `input_dry/` и `pred_xenon/` |
| `z` | номер среза в объёме `univ_v3_bin2` |
| `voxel_um` | 3.690 мкм |
| `phi_abs_error` | \|φ предсказанная − φ эталонная\|, процентные пункты |
| `phi_bias` | то же со знаком |
| `phi_pred`, `phi_real` | пористость среза, % |
| `mae`, `rmse` | повоксельная ошибка φ-карты, п.п. |
| `pearson` | корреляция предсказанной и эталонной φ-карт |
| `sigma_phi_noise` | шум эталона, 12.9 п.п. |
| `offset`, `scale` | константы нормировки для сети |
| `beta`, `d100` | φ = (I_xe − I_air + β) / ΔI₁₀₀ × 100 |
| `phi_pred_debiased` | предсказание минус −1.022 п.п. (константа со Сколтеха) |
| `phi_abs_error_debiased` | ошибка после этой поправки |
| `phi_abs_error_debiased_oracle` | ошибка при константе, подогнанной по этому образцу |

## Ограничение

Профиль пористости по высоте этого керна интерпретировать нельзя: в калибровке
осталось около 2 п.п. систематики, растущей вдоль z, и отделить её от реальной
неоднородности имеющимися данными невозможно. Средняя пористость по объёму
(17.7 %) достоверна.

Собрано скриптом `make_ood_set_univ.py`.
