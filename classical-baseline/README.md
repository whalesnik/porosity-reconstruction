# Классический эталон: карта пористости по паре сканов Air / Xe

Не-ML реализация методики Ebadi et al. (2022) на датасете Skoltech
`hgxdh8ps94-1` (Mendeley DOI 10.17632/hgxdh8ps94.1), полный объём 900×900×900,
разрешение 3 мкм/воксель.

Назначение — **эталон для сравнения ML-моделей**. Без него нельзя отличить
предсказание, физически осмысленное, от просто похожего на глаз.

## Результат

| величина | получено | опубликовано |
|---|---|---|
| **полная пористость** | **13.80 ± 0.75 %** | лаборатория **13.6 %** |
| разрешённая (классика µxCT) | 3.44 % | 6 % |
| субразрешённая | 10.36 % | — |
| разброс по срезам (1σ) | 0.40 п.п. | — |
| медианный диаметр разрешённой поры | 11.4 мкм | ЯМР: хвост за 4–6 мкм |

Собственная ошибка метода измерена **отдельно от лабораторных данных** — на
синтетическом фантоме с известной φ каждого вокселя (`synthetic_test.py`):
**−0.63 п.п.**, β восстанавливается точно.

Опубликованное значение Xe-пайплайна 11.1 % воспроизводится как частный
случай — см. «Что из этого следует».

## Как считается пористость

Воксель крупнее поры содержит смесь твёрдой фазы и пустоты (partial volume
effect). Для доли пор φ:

```
I_air = φ·I_pore_air + (1-φ)·I_solid
I_xe  = φ·I_pore_xe  + (1-φ)·I_solid
------------------------------------------------
ΔI = I_xe - I_air = φ·ΔI₁₀₀        =>   φ = ΔI / ΔI₁₀₀
```

Вклад твёрдой фазы сокращается **тождественно** — в этом смысл метода, и он
сильнее, чем «ксенон даёт больше контраста». В сухом скане яркость вокселя
зависит и от пористости, и от минералогии, и разделить их по одному скану
нельзя. В разности минералогии просто нет.

Насколько это важно, видно на числах образца: воксели, отнесённые к
субразрешённой пористости, имеют в сухом скане медиану **8800** при пике
кварца **8859** — то есть 55 единиц при шуме ~250, **неотличимы от кварца**.
В разности те же воксели дают ΔI ≈ 900 при шуме 110, то есть **8σ**. Их
твёрдая фаза плотнее кварца (глины с K и Fe), и избыточное поглощение почти
точно компенсирует недостачу от пор.

Калибруются два числа, оба — по морфологически чистым опорам (3D-эрозия
масок: воксель, у которого все 26 соседей тоже в окне опорной фазы, шумовым
выбросом быть не может):

```
β     = +265.5   нормализация, по внутренности кварцевых зёрен (φ=0)
ΔI₁₀₀ = 3134     масштаб, по внутренности крупных пор (φ=1)
σ_φ   = 3.5 %    шум повоксельной карты после median 3×3×3
```

Чувствительность жёсткая: **1 п.п. пористости = 32 единицы интенсивности из
8859**, то есть 0.35 % шкалы. Калибровка — не деталь, а основной источник
систематики.

## Установка и запуск

```bash
pip install -r requirements.txt          # pyvista нужен только для render_3d.py
```

Данные ожидаются как срезы PNG рядом со скриптами:
`hgxdh8ps94-1/Air/Air_%04d.png` и `hgxdh8ps94-1/Xenon_/Xe_%04d.png`.

```bash
python xe_pipeline.py --stage all              # калибровка + весь объём (~10 мин)
python xe_pipeline.py --stage run --zstep 10   # быстрая прикидка по 90 срезам
python sensitivity.py                          # бюджет неопределённостей
python figures.py                              # fig1, fig2
python make_3d.py                              # STL + анализ связности
python pore_size.py                            # распределение пор по размерам
python tests.py                                # 13 проверок (--fast: без прогонов)
python synthetic_test.py                       # сквозная проверка на фантоме
```

**Память.** Обработка потоковая, срез за срезом, с записью в `np.memmap`:
полный объём во float32 — это 2.9 ГБ на один стек, и в RAM он не помещается.
Пайплайн отработан на машине с 7.4 ГБ. Ничего не нужно резать до кубика 256³.

**Что получается на выходе** (`results/`, крупные файлы в git не заливаются):

| файл | что это |
|---|---|
| `phi_map.npy` | (900,900,900) uint8, % пористости на воксель, 696 МБ |
| `binary_pores_classic.npy` | разрешённые поры, та же форма |
| `pore_network.stl` | изоповерхность φ=35 %, для ParaView / Blender |
| `calibration.json` | β, ΔI₁₀₀, пороги — **нужен ML-моделям**, см. ниже |
| `stats.json` | профили по z, гистограмма φ, кривая усечения |

## Применение к новым данным

Пути и размер объёма — параметры, код трогать не нужно:

```bash
python xe_pipeline.py --stage all \
    --air "путь/Air/Air_%04d.png" --xe "путь/Xe/Xe_%04d.png" \
    --nz 900 --out results_образец2
```

Обязательно на каждой новой паре сканов:

1. **Перекалибровать.** β и ΔI₁₀₀ зависят от прибора, сессии и давления
   ксенона. Переносить числа между образцами нельзя.
2. **Проверить регистрацию** (`diagnostics/explore.py`). У нас сдвиг оказался
   нулевым — объёмы совмещены на источнике, — но это свойство датасета, а не
   метода. При ненулевом сдвиге нужна 3D-регистрация ПЕРЕД вычитанием, иначе
   разность даст краевые диполи вместо пор.
3. **Проверить, что резкость сканов одинакова** (`diagnostics/check_psf.py`).
   Разный PSF даёт ореолы вокруг пор: интегральная пористость выживает
   (свёртка сохраняет среднее), повоксельная карта и связность — нет.

Встроенный контроль, не требующий ни лаборатории, ни статьи: **хвост
распределения φ обязан гаснуть на 100 %** (`fig2`, левая панель). Уходит за
125 % — ΔI₁₀₀ занижен; не дотягивает до 90 % — завышен.

Тревожные признаки в логах калибровки:

- расхождение двух твёрдых опор много больше 100 единиц → α заметно отличается
  от 1, его надо оценивать, а не принимать равным единице;
- порог опорных пор ушёл на перцентиль 9–13 → крупных пор почти нет, ΔI₁₀₀
  занижен;
- разброс β по срезам больше ~30 единиц → калибровка нестабильна по высоте,
  в объёме появится полосатость по z.

**Когда метод не сработает:**

- в образце нет разрешённых пор — ΔI₁₀₀ измерить не по чему, придётся задавать
  извне (из давления и состава газа);
- опорная минеральная фаза сама микропориста — пористость занижается ровно на
  пористость опоры. Метод меряет φ **относительно опоры**; всё, что есть в ней
  самой, невидимо. Для чистого кварца пренебрежимо, для карбонатов и сильно
  глинистых пород опору надо выбирать осознанно.

## Для ML-моделей

`xe_pipeline.compare_phi_maps(predicted_phi, real_phi)` → `mae`, `rmse`,
`bias`, `phi_pred`, `phi_real`, **`phi_abs_error`**, `phi_rel_error`,
`pearson`. Это ошибка на **итоговой физической величине**, а не на изображении.

Порядок применения: предсказанный Xe-скан → **та же** калибровка из
`calibration.json` → φ-map → сравнение с референсной.

Три правила, нарушение которых обесценивает сравнение:

1. **Не перекалибровывать на предсказании.** Иначе модель «объяснит»
   собственное смещение и сравнение закольцуется.
2. **Никакой per-image нормализации на выходе модели.** 1 п.п. пористости =
   0.35 % шкалы интенсивностей. Любая нормализация на изображение убивает
   абсолютную шкалу, а с ней и всю пористость.
3. **SSIM недостаточно.** Он нормирован и оценивает структуру локально, поэтому
   модель, верно воспроизводящая текстуру, но сжимающая динамический диапазон,
   получит отличный SSIM и неверную пористость. Проверено на имитации: Pearson
   0.978 при промахе по пористости 1.4 п.п.

## Что из этого следует

**Почему в статье 11.1 %, а в лаборатории 13.6 %.** Их φ-map присваивает φ=0
всему за пределами сегментированной «porous part», а линейку калибрует по
гистограмме только этих вокселей. Диффузный хвост слабой микропористости
срезается. Воспроизведение их рецепта на наших данных даёт **11.05 %** при
porous part = 29 % объёма (`paper_method.py`). Оценка без обнуления сохраняет
хвост и попадает в лабораторное значение.

**Интегральную пористость нельзя считать с клиппингом.** Шум симметричен и в
среднем сокращается; обрезав отрицательные φ, оставляем только положительный
хвост шума. На этих данных клиппинг давал 14.05 % против 9.70 % без него на
одной калибровке. Стоит проверить, не клиппуется ли выход ML-моделей.

**Разрешённая поровая сеть образец не протыкает.** При φ≥50 % крупнейший
кластер держит 12 % пор и перколяции нет; при φ≥40 % — 55 % и перколяция есть
(`make_3d.py`). Проницаемость 0.059 мД обеспечивается субразрешённой фазой, и
модель течения по одним разрешённым порам дала бы ноль.

**Морфология проверена объективно.** Медианный диаметр разрешённой поры
11.4 мкм, диапазон 6–60 мкм — это правый хвост ЯМР-распределения из статьи за
линией разрешения. Основная популяция пор породы (~1–3 мкм) лежит ниже вокселя,
поэтому 3D-модель разрешённых пор и должна выглядеть разреженной.

## Тесты

```bash
python tests.py            # 13 проверок, ~5 мин
python tests.py --fast     # без прогонов пайплайна, ~5 с
```

Проверяются свойства, обязанные выполняться точно: вырожденный вход обязан
падать с внятным сообщением, а не выдавать правдоподобный мусор; сдвиг и
масштаб обоих сканов не меняют φ; шаг по z не меняет интегральную φ; прогон
детерминирован. Отдельно сторожится, что φ-карта на диске — полный изотропный
объём: связность по прореженному по z объёму считать нельзя, при медианной поре
в 4 вокселя прореживание рвёт поровую сеть и даёт уверенный неверный ответ.

Гоняйте их после любой правки калибровки — три из четырёх ошибок, найденных
этими тестами, давали не падение, а тихий сдвиг пористости.

## Грабли

Всё перечисленное было проверено на этих данных и даёт **правдоподобно
неверный** результат — то есть молча, без ошибки времени выполнения.

| приём | что даёт | почему неверно |
|---|---|---|
| нормализация по перцентилям 1/99 | — | перцентиль 1 — это поры: нормировка стирает искомый сигнал |
| Otsu для порога пор | порог выше пика кварца | распределение унимодальное, поры — 6 % в левом хвосте |
| условные медианы I_xe(I_air) | α = 0.80 | regression dilution: биннинг по шумной переменной занижает наклон |
| Q-Q маргинальных гистограмм | кварц уезжает на −311 | Xe переносит массу из левого хвоста вправо, маргинал — не аффинный образ |
| мода Xe-гистограммы как опора | сдвиг −300 | мода Xe — не кварц, а переехавшие пористые воксели |
| сегментация по сырому сухому скану | медианный объект 6 вокселей вместо 34 | порог сидит в 1.1σ от границы, связные тела дробятся в шум |
| фиксированный перцентиль опорных пор | падение калибровки | при узкой поровой популяции 3D-эрозия не оставляет вокселей (исправлено адаптивным подбором) |

Общее правило: **любая оценка из гистограммы вблизи пика кварца загрязнена
шумом**, потому что кварц занимает ~45 % объёма и его шумовые выбросы
доминируют в соседних корзинах. Поэтому опоры берутся морфологией, а не
гистограммой.

## Ограничения

- **α = 1 принято, а не измерено.** Две твёрдые опоры расходятся на 97 единиц,
  что отвечает α ≈ 0.976. Вклад ±0.29 п.п. На другом приборе проверять заново.
- **Доминирует неопределённость ΔI₁₀₀** (±0.66 п.п. из суммарных ±0.75).
  Уточняется на образце с более крупными порами, где эрозия оставляет чистую
  опору.
- **Опора «кварц»: медиана против моды.** Распределение скошено вправо
  (в окно попадает микропористая глина), и мода дала бы β = 300.7 вместо
  265.5, то есть +1.07 п.п. Вариант отклонён: независимая опора на плотных
  включениях даёт β ≈ 277.5, что согласуется с медианой до 5.6 единиц, а с
  модой расходится на 23. Если на новых данных глинистой фазы больше —
  перепроверить (`diagnostics/check_anchor.py`).
- **Деление на разрешённую и субразрешённую зависит от соглашения о пороге**
  (у нас φ=50 %, в статье — 6 % объёма). Полная пористость от порога не
  зависит вовсе: она считается только по ΔI.
- **Денойзинг — параметр калибровки, а не косметика.** По четырём режимам
  (none/median3/median5/gauss) φ расходится на 0.28 п.п.: на средний ΔI фильтр
  почти не влияет, но ΔI₁₀₀ считается как `p90 − 1.2816·σ`, а σ зависит от
  фильтра.
